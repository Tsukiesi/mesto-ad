# Mesto

Проектная работа «Mesto. Работа с сервером».

Приложение подключено к API: загружает данные пользователя и карточки, позволяет редактировать профиль и аватар, добавлять, лайкать и удалять карточки, а также смотреть статистику карточки (кнопка «i» в левом верхнем углу).

**Ссылка на опубликованный проект:** https://Tsukiesi.github.io/mesto-deploy/

## Запуск

Нужен Node.js 20.19+ или 22.12+.

- `npm install` — установка зависимостей;
- `npm run dev` — сервер разработки (страница открывается автоматически);
- `npm run build` — сборка проекта в папку `dist`;
- `npm run deploy` — сборка и публикация проекта на GitHub Pages.

Публикация также выполняется автоматически через GitHub Actions (`.github/workflows/deploy.yml`) при каждом push в ветку `main`.
